# Blur
- [Github地址：f0e/blur](https://github.com/f0e/blur)

支持`windows`、`linux`、`macos`三平台，一个小而美的给视频加上运动模糊的工具，可以对参数进行精细化调整，下面是仓库展示的经渲染后的CS:GO画面：

# Video2X
- [Github地址：k4yt3x/video2x](https://github.com/k4yt3x/video2x)

一款强大的开源机器学习类，视频超分、视频补帧的后期工具，支持御三家GPU，以及AMD、Intel的CPU渲染。

# mpc-hc
原版MPC-HC已经在2017年停更了，这里要安利的是fork版本：[clsid2/mpc-hc](https://github.com/clsid2/mpc-hc)

一款克制的视频播放器，仅支持Windows，当然比较流行的还有其他三款：
- potplayer：有其社区争议
- vlc：UI复古
- mpv：非常自由，但要折腾

# hatoba
- [Github地址：scarletkc/Hatoba](https://github.com/scarletkc/Hatoba)

一款比较新的SSH客户端，支持cloudflare-worker来对客户端信息进行持久化同步与加密保存，解决不同机器之间的信息不同步问题；同时内置一个dev-agent，能够自由配置模型，并在ssh时进行AI辅助，采取比较保守的命令执行策略，默认询问，但可以配置`jev`这样的决策模型进行自动决策，也可以完全放开；目前仍在开发早期阶段，但已经很好用了个人觉得。

# PrismLauncher
- [Github地址：PrismLauncher/PrismLauncher](https://github.com/PrismLauncher/PrismLauncher)

国内的PCL2屡屡遭遇风波，可以考虑这款功能比较强大的Minecraft启动器，但可能不够“开箱直用”和“直观”，但对于一些高级功能，这款启动器开放的比较多，适合对Minecraft游戏目录、模组整合包生态有一定熟悉度的用户。

启动器支持四平台，在原常见的三家操作系统之外，还支持了SteamOS的SteamDeck原生应用，可以说十分全面了。
