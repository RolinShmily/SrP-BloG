# 设计规范

本文定义 SrP-BloG 的视觉语言与交互基线。它不追求覆盖每个组件的每个类名，而是给出**做新界面时必须遵守的约束**；具体实现以 `src/styles/`、`tailwind.config.ts` 与组件源码为准。

## 1. 设计定位

关键词：**编辑感、克制、技术性、双语优先**。

- 内容优先：文章、标题、标签和元信息是主角，装饰不能抢阅读注意力。
- 单强调色：整体是 Zinc 灰阶，品牌粉只用于当前状态、置顶、悬停标题、选中标签等少数位置。
- 轻量动效：动效解释状态变化（进入、折叠、回缩、悬停），不做无意义的持续运动。
- 双语是结构，不是翻译层：中英文在 DOM 中同时存在，由属性切换显示，不产生路由前缀或重复构建。
- 明暗双主题对等：每个新组件都必须同时在 `light` 与 `dark` 下检查，不能只做一套再“顺手补另一套”。

## 2. 色彩系统

### 2.1 语义色

颜色以 HSL 通道存储在 CSS 变量中，由 Tailwind 映射为 `bg-background`、`text-foreground`、`border-border` 等语义类。**业务组件应使用语义类，不要直接写十六进制颜色**（品牌粉的既有例外见 2.2）。

| Token | Light | Dark | 用途 |
| --- | --- | --- | --- |
| `--background` | `0 0% 100%` | `0 0% 2%` | 页面底色 |
| `--foreground` | `240 10% 3.9%` | `0 0% 98%` | 主文字 |
| `--card` | `0 0% 100%` | `240 6% 3.8%` | 卡片表面 |
| `--muted` | `240 4.8% 95.9%` | `240 4% 10%` | 次级表面、代码头 |
| `--muted-foreground` | `240 3.8% 46.1%` | `240 5% 64.9%` | 次级文字 |
| `--border` | `240 5.9% 90%` | `240 4% 13%` | 边框、分隔线 |
| `--ring` | `240 5.9% 10%` | `240 4.9% 83.9%` | 焦点环 |
| `--radius` | `0.5rem` | 同左 | 基础圆角 |

深色背景使用近黑 `#050505` 级别的 obsidian 画布，卡片略亮一档；浅色模式使用纯白画布与 Zinc 灰阶。

### 2.2 品牌强调色

```css
--accent-pink: #f75c7e;
--accent-bright: #ff7eb3;
--accent-soft: #ffa4c6;
--accent-glow: rgba(247, 92, 126, 0.25);
```

使用范围：

- 当前导航项的粉点；
- 置顶徽标图标；
- 卡片标题悬停、标签链接悬停；
- 选中标签的粉色描边/圈选；
- 品牌字标中的撇号渐变；
- 搜索高亮、页面进度条等少量反馈。

既有组件中有一部分直接使用 `#f75c7e`，与 `--accent-pink` 取值相同。**新增代码优先使用 CSS 变量**，不要引入新的粉色系色值。

### 2.3 文章灰阶阶梯

正文不使用纯黑，而是四档灰阶表达层级（浅色模式从深到浅，深色模式反向）：

| Token | Light | Dark | 用途 |
| --- | --- | --- | --- |
| `--article-fg-deeper` | `240 6% 7%` | `240 5% 96%` | 文章 H1、链接 |
| `--article-fg-deep` | `240 5% 13%` | `240 4% 87%` | H2、strong、行内代码 |
| `--article-fg` | `240 4% 34%` | `240 4% 73%` | 正文 |
| `--article-fg-muted` | `240 4% 46%` | `240 4% 58%` | 图注、有序列表序号 |

对比度目标：正文与图注在各自背景下不低于 4.5:1。新增文章排版样式时，从这四档取值，不要临时造第五档灰。

### 2.4 选区

- 浅色：`#b3d4fc`；
- 深色：`#084c59`。

## 3. 字体与排版

### 3.1 字体家族

| 变量 | 家族 | 用途 |
| --- | --- | --- |
| `--font-latin` | Inter | 拉丁正文、标题 |
| `--font-cjk-sc` | Noto Sans SC | 中文正文与标题 |
| `--font-mono-latin` | JetBrains Mono | 代码、日期、标签云计数、导航等宽元素 |
| `--font-display` | Instrument Serif | 仅品牌展示（“BloG”字标） |

`--font-sans` 的顺序是 `Inter → Noto Sans SC → 系统回退`，实现逐字形回退：拉丁字符走 Inter，汉字走 Noto Sans SC。`--font-mono` 同理，汉字回退到 Noto Sans SC，再回退到系统等宽字体。

字体全部由本站同源提供（构建期生成 `public/fonts/`），**不得在运行时引入 Google Fonts 外链**。新增字体家族需要同时更新抓取脚本、变量、许可声明与 Notice，见 [架构规范 · 字体](../architecture/README.md#9-字体)。

### 3.2 排版规则

- 基础正文：16px；行高由 `@tailwindcss/typography` 的 prose 配置与组件类控制。
- 页面主标题：`text-2xl sm:text-3xl` 或首页 `text-3xl sm:text-4xl`，`font-semibold tracking-tight`。
- 元信息：`text-meta`（0.8125rem / 1.25rem），通常搭配 `font-mono`。
- 标题统一 `tracking-tight`；正文强调通过字重与灰阶，而不是颜色噪音。
- 文章正文只允许一个 `<h1>`（页面标题）；Markdown 标题在渲染时整体降一级。
- 代码、日期、快捷键、标签计数使用等宽字体；中文正文不要使用等宽字体。
- Inter 启用 `cv02/cv03/cv04/cv11` 字形变体；全局开启 `optimizeLegibility` 与抗锯齿。

### 3.3 `text-meta` 的约束

`text-meta` 是项目自定义的字号 token（`tailwind.config.ts`），同时注册在 `src/lib/utils.ts` 的 `CUSTOM_FONT_SIZE_TOKENS` 中，供 `tailwind-merge` 正确分类。新增自定义字号必须同时改这两处，`pnpm verify-content` 会检查一致性。

## 4. 布局与间距

- 内容列：`max-w-5xl`（64rem / 1024px），水平内边距 `px-4 sm:px-6`。
- 页面垂直节奏：`py-8 sm:py-12`；主要区块间距 `space-y-10`。
- 卡片内边距：列表卡 `p-5 sm:p-6`，置顶大卡 `p-6 sm:p-8`。
- 圆角：
  - 基础 `--radius: 0.5rem`；
  - 列表卡、置顶卡、导航胶囊 `rounded-xl` / `sm:rounded-2xl`；
  - 文章封面 `rounded-2xl`；
  - 徽标、标签、按钮按组件语义使用 `rounded-md` / 全圆角。
- 边框：默认 `border-border`；弱化的卡片边缘使用 `border-border/60` 或 `/70`。
- 卡片表面：列表卡默认半透明 `bg-card/40`，悬停提升到 `bg-card/75`；置顶卡从 `/80` 提升到实色 `bg-card`。
- 背景艺术：默认 `ArtPlum` 冬梅画布，固定定位、`pointer-events-none`、`aria-hidden`；可通过 `?art=plum|dots|none` 临时覆盖，或用 `siteConfig.ambientArt` 全局关闭。

## 5. 组件语言

### 5.1 文章卡片

- 结构：元信息行 → 标题 → 摘要 → 字数/阅读时长 → 封面与箭头。
- 封面不是独立画框：它贴在卡片尾侧，用 `.blend-cover` 蒙版淡入阅读侧，图片与卡片表面读作同一平面。
- 整卡可点击通过**拉伸覆盖链接**实现，而不是把整块包进 `<a>`；标签链接提升到 `z-20`，保持独立可点。
- 悬停只加深表面与标题颜色，不做位移动画或大面积着色。
- 有封面时标题/摘要限制行数，避免卡片高度失控。

### 5.2 置顶大卡

- 只用于 `pinned` 文章；版式与列表卡相同，但字号更大、表面更实，作为列表上方唯一的“主位”。
- 封面在宽屏占尾侧约 3/5 宽度；窄屏改为顶部横带。

### 5.3 浮动导航

- 静止态：透明、无边框、圆角胶囊，链接分布在内容列两侧。
- 滚动超过约 20px：出现细边框、实色表面、分层阴影、收紧内边距；≥800px 时左右各收 8%。
- 向下滚动超过约 350px 且继续向下：整条导航上移收起；向上滚动立即恢复。**挂载时不判断收起状态**，避免滚动恢复导致首屏导航消失。
- 当前页面：文字提升到前景色，并在下方显示 2px 粉色圆点。
- 移动端：`md` 以下切换为菜单按钮；面板用 `grid-template-rows: 0fr → 1fr` 展开，收起时 `visibility: hidden`，避免焦点落入不可见链接。

### 5.4 文章页

- 顺序：返回链接 → 封面（可选）→ 出处信息行 → 标题 → standfirst → 正文 → 版权卡 → 评论。
- 封面使用 16:9 容器，后方叠加同图模糊光晕；点击/回车打开图片预览。
- 出处信息行使用等宽字体：置顶、发布日期、更新日期、阅读时长、阅读量、标签。
- 桌面端目录吸附在文章右侧（`xl` 以上）；移动端折叠为可展开的目录。
- 代码块带独立头部：语言标签、折叠按钮、复制按钮；Shiki 双主题在明暗模式间切换。
- 正文容器带 `data-pagefind-body`，页脚/导航不进入搜索索引。

### 5.5 标签云

- 字号随文章频次在约 `0.85rem` 到 `1.3rem` 之间线性缩放，频次相同的标签保持同一视觉权重。
- 未选中标签保持中性灰阶；选中标签使用粉色描边/圈选。
- 默认多选，支持 OR / AND 两种匹配模式；筛选状态同步到 `?tag=`，刷新可恢复。
- 选中/清除筛选**不得强制滚动页面**，保持视口稳定。

### 5.6 搜索、预览与反馈

- 搜索通过 `Cmd/Ctrl + K` 呼出；结果展示标题、上下文片段与高亮。
- 图片预览支持键盘操作与 Esc 关闭。
- 页面切换使用统一的进入动画；路由 query 变化（如标签筛选）不触发整页重放。
- 加载、失败、空状态都应保持文案与布局稳定，不因异步数据到达产生明显跳动。

### 5.7 页脚与品牌

- 页脚使用等宽字体，信息密度高于正文；快速链接、社交、技术栈分别成组。
- 技术栈跑马灯在 `prefers-reduced-motion: reduce` 下停止。
- 品牌字标由手绘感 `SrP` 单线与 Instrument Serif 斜体 “BloG” 组成；撇号使用品牌粉渐变。悬停时重放描边动画是唯一允许的“装饰性重播”。

## 6. 动效

| 场景 | 时长 | 缓动 |
| --- | --- | --- |
| 颜色、边框、背景等状态变化 | 150–200ms | `ease` |
| 布局收放、导航胶囊变形 | 300ms | `ease` 或 `cubic-bezier(0.16, 1, 0.3, 1)` |
| 页面进入 | 320ms | `cubic-bezier(0.16, 1, 0.3, 1)` |
| 区块错峰进入 | 340ms + 60ms/项 | 同上 |
| 卡片错峰进入 | 380ms + 35ms/项 | `cubic-bezier(0.22, 1, 0.36, 1)` |
| 品牌描边 | 550ms / 悬停 450ms | `cubic-bezier(0.45, 0, 0.2, 1)` |

规则：

- **禁止 `transition: all`**。只列出确实需要动画的属性，避免字体加载、布局变化被意外补间。
- 悬停位移/缩放只在 `@media (hover: hover)` 下启用，触屏不触发。
- 所有装饰性动画必须在 `prefers-reduced-motion: reduce` 下关闭（页面进入、卡片错峰、聚光、标签浮动、跑马灯、导航回缩）。
- 动效不得改变布局占位；进入动画使用 opacity + transform，不触发布局重排。

## 7. 响应式

使用 Tailwind 默认断点：

| 断点 | 宽度 | 主要变化 |
| --- | --- | --- |
| `sm` | 640px | 页面内边距、卡片内边距增大；卡片封面从顶部横带变为尾侧面板 |
| `md` | 768px | 桌面导航出现，移动菜单隐藏 |
| `lg` | 1024px | 页脚恢复三列网格 |
| `xl` | 1280px | 文章目录变为右侧吸附栏 |

额外规则：

- 导航胶囊在 `min-width: 800px` 时执行滚动收窄。
- 移动端优先保证单列阅读：卡片、标签云、文章元信息均允许换行。
- 任何新页面至少检查 360px、768px、1280px 三个宽度。

## 8. 双语设计

- 静态 HTML 同时包含中英文文本：`<T zh={...} en={...} />` 输出两个带 `data-i18n` 的内层节点，根元素 `data-locale` 决定 CSS 显示哪一个。
- 语言在首屏绘制前由内联脚本写入 `<html data-locale>`，避免错误语言闪烁；`?lang=` 优先于 `localStorage`。
- UI 不使用 `/zh`、`/en` 路由前缀；切换语言不触发导航。
- 设计时按**较长语言**预留空间：按钮、标签、导航项避免固定宽度；中英文都可能换行的地方允许 `flex-wrap`。
- 文章内容语言由 frontmatter `lang` 标记，影响 `og:locale`；界面语言与文章语言相互独立。

## 9. 可访问性

- 所有可交互元素提供可见的 `focus-visible` 焦点环（`ring-2 ring-ring ring-offset-2`）。
- 图标按钮必须有 `aria-label`；纯装饰图形使用 `aria-hidden="true"`。
- 图片必须有非空 `alt`；`verify-seo` 会把缺失或空 alt 视为构建错误。
- 图片预览、移动菜单、搜索对话框必须支持键盘打开/关闭。
- 颜色不是唯一信息载体：当前导航项同时有颜色与圆点，选中标签同时有描边与状态文本。
- 正文灰阶与图注对比度不低于 4.5:1。
- 尊重 `prefers-reduced-motion`；尊重 `color-scheme`，表单控件跟随主题。

## 11. 新增 UI 检查清单

- [ ] 使用语义色与既有圆角/间距 token，没有引入新色值或新字号。
- [ ] 浅色与深色都检查过，悬停/焦点/禁用状态完整。
- [ ] 中文与英文都检查过，较长文案不溢出、不遮挡。
- [ ] 360px / 768px / 1280px 三个宽度下布局成立。
- [ ] 键盘可操作，焦点可见，图标有可读标签。
- [ ] 动效在 `prefers-reduced-motion` 下关闭，且没有 `transition: all`。
- [ ] 图片有非空 `alt`，装饰元素 `aria-hidden`。
- [ ] 若改变视觉基线，已更新 `docs/screenshot/` 中对应截图。
