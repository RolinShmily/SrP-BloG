# 界面截图

本目录保存 README 与设计评审使用的界面基线截图。它们不是测试快照，而是**当前视觉约定的人工基线**。

## 文件

| 文件 | 页面 / 状态 |
| --- | --- |
| `home-light.webp` | 首页，浅色模式 |
| `home-dark.webp` | 首页，深色模式 + 英文 UI |
| `article.webp` | 文章详情，桌面端 |
| `article-mobile.webp` | 文章详情，手机端（目录展开） |
| `archives.webp` | 归档页 |
| `tags.webp` | 标签云与筛选 |
| `search.webp` | Pagefind 搜索结果 |
| `home-mobile.webp` | 首页，手机端 |

## 更新约定

- 命名统一为 `<页面>-<状态>.webp`，例如 `home-dark.webp`；替换时保持文件名不变，避免 README 与 [设计规范](../design/README.md) 的链接失效。
- 截图应与当前 `main` 的视觉基线一致；改版 PR 中同时更新受影响的截图。
- 使用 WebP，保持宽度一致（桌面截图建议 1280px 级，手机截图建议 360–390px 级），避免仓库体积膨胀。
- 截图前确认：浅色/深色、中文/英文、桌面/手机至少覆盖 README 中展示的组合。
- 不要截入个人隐私数据、真实评论者信息或本地路径。

截图同时是 [设计规范 · 视觉基线](../design/README.md#10-视觉基线) 的检查对象。
