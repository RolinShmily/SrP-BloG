## 概述说明

**SrP-BloG** 是一个基于 [Astro](https://github.com/withastro/astro) 框架构建的个人静态技术博客网站。本项目基于 [saicaca](https://github.com/saicaca) 开发的 [Fuwari](https://github.com/saicaca/fuwari) 模版进行二次定制与功能扩展。
